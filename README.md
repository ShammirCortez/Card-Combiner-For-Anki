# Card-Combiner-For-Anki
I'm learning russian, and my main way to learn is using yomitan to add cards to my anki deck, but in russian, verbs have imperfective and perfective forms. Yomitan has a different card for each form of the verb, making learning on anki much more difficult when studing 1 version of a word but not the other, when you should be doing twice at once. This is my custom anki addon that I use to combine the two cards instead of doing it manually like I have for the past year.

Project setup was created in Pycharm community, following Anki's official addon guide: https://addon-docs.ankiweb.net/editor-setup.html

Lucky I use Pycharm community for school too!!
